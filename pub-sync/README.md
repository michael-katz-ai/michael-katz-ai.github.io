# Publication Synchronization Pipeline

This directory contains tools to extract, merge, deduplicate, and format publications from BibTeX and CV sources into a structured JSON format for the website.

## Quick Start

To run the entire pipeline from start to finish:

```bash
cd new-site/pub-sync
./run_full_pipeline.sh [BIB_DIR] [CV_PATH]
```

**Parameters:**
- `BIB_DIR` (optional): Directory containing BibTeX files (default: `../../bib`)
- `CV_PATH` (optional): Path to CV LaTeX file (default: `../../CV_Michael_Katz.tex`)

**Examples:**
```bash
# Use default paths (../../bib and ../../CV_Michael_Katz.tex)
./run_full_pipeline.sh

# Specify custom BibTeX directory
./run_full_pipeline.sh /path/to/bib

# Specify both custom paths
./run_full_pipeline.sh /path/to/bib /path/to/CV.tex
```

**BibTeX Directory Structure:**
The BibTeX directory should contain:
- `literatur.bib` - Main BibTeX file with publications
- `crossref.bib` - Crossref entries for venue information
- `abbrv.bib` - Abbreviations for journal/conference names

This will:
1. Extract publications from BibTeX (literatur.bib with crossref and abbreviations)
2. Extract publications from CV LaTeX file
3. Merge the two sources
4. Deduplicate publications
5. Apply categorization to uncategorized publications
6. Use existing `paper_order.json` (or generate if first run)
7. Format final website JSON using `topic_order.json` and `paper_order.json`

**Important:** Both `topic_order.json` and `paper_order.json` are **preserved between runs**:
- `topic_order.json` - Controls category/subcategory order (manually maintained)
- `paper_order.json` - Controls paper order within subtopics (generated once, then manually edited)

The pipeline will never overwrite these files once they exist.

## Pipeline Steps

### 1. Extract from BibTeX
```bash
python3 bibtex_to_jsonl.py ../katz.bib katz_bibtex.jsonl
```
- Reads BibTeX file with crossref resolution
- Extracts publication metadata
- Filters out Zenodo entries (howpublished contains "zenodo")
- Output: `katz_bibtex.jsonl` (one JSON object per line)

### 2. Extract from CV
```bash
python3 cv_to_jsonl.py ../CV_Michael_Katz.pdf katz_cv.jsonl
```
- Extracts publications from CV PDF
- Parses categories and subcategories
- Output: `katz_cv.jsonl`

### 3. Merge Publications
```bash
python3 merge_publications.py katz_bibtex.jsonl katz_cv.jsonl katz_unified.jsonl
```
- Merges BibTeX and CV data
- BibTeX provides detailed metadata
- CV provides categorization
- Output: `katz_unified.jsonl`

### 4. Deduplicate
```bash
python3 deduplicate_publications.py katz_unified.jsonl katz_unified_deduplicated.jsonl
```
- Removes duplicate publications
- Priority: Journal > Conference > Workshop > Tech Report
- Keeps the highest priority version
- Output: `katz_unified_deduplicated.jsonl`

### 5. Apply Categorization
```bash
python3 apply_uncategorized_resolution.py katz_unified_deduplicated.jsonl uncategorized_resolution.json katz_unified_categorized.jsonl
```
- Applies categorization from `uncategorized_resolution.json`
- Excludes specified publications
- Output: `katz_unified_categorized.jsonl`

### 6. Generate Paper Order (First Time Only)
```bash
python3 generate_paper_order.py katz_unified_categorized.jsonl paper_order.json
```
- Creates `paper_order.json` with current paper order (chronological by default)
- **Only run this manually if you want to reset/regenerate the order**
- The pipeline script preserves existing `paper_order.json`
- Edit this file to manually reorder papers
- Output: `paper_order.json`

### 7. Format for Website
```bash
python3 format_website_json_v2.py katz_unified_categorized.jsonl ../data/publications.json
```
- Formats publications for website display
- Uses `topic_order.json` for category/subcategory order
- Uses `paper_order.json` for paper order (if exists)
- Output: `../data/publications.json`

## Configuration Files

### `topic_order.json` (Manual - Never Overwritten)
Controls the order of research topics and subtopics on the website.

**This file is manually maintained and never regenerated by the pipeline.**

Structure:
```json
{
  "topics": [
    {
      "name": "Topic Name",
      "id": "topic-id",
      "description": "Topic description",
      "subtopics": ["Subtopic 1", "Subtopic 2"]
    }
  ]
}
```

To reorder topics: Edit the `topics` array order
To reorder subtopics: Edit the `subtopics` array within each topic

### `paper_order.json` (Generated Once - Then Manual)
Specifies the order of papers within each subtopic.

**This file is generated on first run, then preserved. Edit it to manually reorder papers.**

Structure:
```json
{
  "paper_order": {
    "Category Name": {
      "Subcategory Name": ["paper-id-1", "paper-id-2"]
    }
  }
}
```

To reorder papers: Edit the BibTeX key arrays within each subcategory
To reset to chronological: Delete the file and run the pipeline again

### `uncategorized_resolution.json` (Manual)
Maps uncategorized publications to categories and specifies exclusions.

Structure:
```json
{
  "add_to_cv": {
    "Category Name": {
      "Subcategory Name": ["paper-id-1", "paper-id-2"]
    }
  },
  "exclude": {
    "papers": [
      {"id": "paper-id", "reason": "Reason for exclusion"}
    ]
  }
}
```

## Manual Ordering

### Reorder Topics/Subtopics

Edit `topic_order.json`:
- Reorder items in the `topics` array to change topic order
- Reorder items in each `subtopics` array to change subtopic order
- Run the pipeline to apply changes

### Reorder Papers Within Subtopics

1. **First time:** Run the pipeline to generate `paper_order.json`:
   ```bash
   ./run_full_pipeline.sh
   ```

2. Edit `paper_order.json` and reorder the BibTeX keys in each subtopic array

3. Run the pipeline again (it will preserve your custom order):
   ```bash
   ./run_full_pipeline.sh
   ```

**Notes:**
- Both `topic_order.json` and `paper_order.json` are preserved between runs
- To reset paper order to chronological: delete `paper_order.json` and run pipeline
- The pipeline never modifies these files once they exist

## Output Files

- `katz_bibtex.jsonl` - Publications extracted from BibTeX
- `katz_cv.jsonl` - Publications extracted from CV
- `katz_unified.jsonl` - Merged publications
- `katz_unified_deduplicated.jsonl` - Deduplicated publications
- `katz_unified_categorized.jsonl` - Categorized publications (final intermediate)
- `paper_order.json` - Paper order configuration (for manual editing)
- `../data/publications.json` - Final website JSON

## File Format: JSONL

All intermediate files use JSONL (JSON Lines) format - one JSON object per line. This allows for:
- Streaming processing of large datasets
- Easy line-by-line inspection
- Efficient merging and filtering

Example:
```jsonl
{"id": "paper1", "title": "Title 1", ...}
{"id": "paper2", "title": "Title 2", ...}
```

## Troubleshooting

### Missing publications
- Check if the publication is in `katz.bib`
- Check if it's being filtered (e.g., Zenodo entries)
- Check `uncategorized_resolution.json` for exclusions

### Wrong category
- Edit `uncategorized_resolution.json` to add/change categorization
- Re-run from step 5 onwards

### Wrong order
- Edit `paper_order.json` to reorder papers
- Re-run step 7 only

### Duplicate publications
- Check deduplication logic in `deduplicate_publications.py`
- Priority: Journal > Conference > Workshop > Tech Report

## Adding New Publications

1. Add to `../katz.bib` with proper BibTeX entry
2. Update `../CV_Michael_Katz.pdf` with categorization
3. Run the full pipeline: `./run_full_pipeline.sh`
4. If uncategorized, add to `uncategorized_resolution.json` and re-run from step 5

## Notes

- The pipeline is idempotent - running it multiple times produces the same result
- All scripts use UTF-8 encoding for proper handling of special characters
- BibTeX crossref entries are resolved from `crossref.bib`
- The system maintains 98.9% synchronization between BibTeX and CV sources
